# OpenObserve SDK OpenTelemetry extensions for OkHttp

See the dedicated [OpenObserve SDK instrumentation for OkHttp documentation][1] to learn how track network requests made by the `OkHttp` library automatically.
See the dedicated [OpenObserve SDK Android for OpenTelemetry documentation][2] to learn how to add a parent span to network requests made by the `OkHttp` library.
